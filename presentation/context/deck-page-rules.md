# กติกาทำหน้า deck (Slidev · theme D) — สำหรับ subagent

> อ่านคู่กับ `context/design-brief.md` (ส่วน "การตัดสินใจ") · หน้าตัวอย่างที่ผ่านแล้ว: `deck/pages/SQ04_S020.md`
> ภาพตัวอย่างหน้า: `renders/shots/main/SQ04_S020.png`

## งานของคุณ

ทำ **เนื้อหน้า** ของหน้าที่ได้รับมอบหมาย เป็นไฟล์ `deck/pages/<รหัสหน้า>.md` — หนึ่งไฟล์ต่อหน้า
สเปกของแต่ละหน้าอยู่ใน `context/script.md` (หัวข้อ `### <รหัสหน้า>`): `ภาพ:` = สิ่งที่ต้องเห็น · `ขั้น:` = หนึ่งบรรทัดหนึ่งคลิก ·
`การ์ดสรุป:` = ข้อความการ์ดท้ายหน้า · `พูด:` = สิ่งที่ผู้พูดจะพูด (ไม่ต้องขึ้นจอ)

ไฟล์หน้าทำมือ = **เนื้อหน้าใต้หัวข้อเท่านั้น** — หัวข้อ แถบตอน ป้าย เลขหน้า และโน้ต `tools/gen_deck.py` ใส่ให้เอง
บรรทัดแรกเขียน `<!-- clicks: N -->` ถ้าหน้ามีคลิก (N = จำนวนคลิกหลังเข้าหน้า = จำนวนบรรทัด `ขั้น:` − 1)

## ห้าม

- **ห้ามแก้ไฟล์อื่นนอกจาก `deck/pages/<หน้าที่ได้รับ>.md`** — ไม่แก้ components, layouts, style.css, tools, script.md, claims.yaml
  ต้องการ component ใหม่หรือข้อมูลเพิ่ม → เขียนบอกในรายงานตอนจบ ไม่ต้องทำเอง
- **ห้าม commit** · ห้ามรัน `git` คำสั่งที่เปลี่ยนสถานะ
- **ห้ามพิมพ์ตัวเลขเองในข้อความที่มองเห็น** — ตัวเลขทุกตัวบนจอต้องเป็น
  `<Fact id="<key ใน data/facts.json>" :digits="N" />` (มี `:index`, `absval`, `:round-to`, `sign` ด้วย — ดู `deck/components/Fact.vue`) หรือ
  `<Lit v="1997" c="C20" />` เมื่อ claim ประกาศเลขนั้นไว้เป็น `lit` ใน `context/claims.yaml` (ใช้ claim ที่หน้านั้นอ้าง)
  ตัวเลขใน attribute ของ component (ตำแหน่ง ขนาด ช่วงแกน) และใน `<style>` ไม่นับ · ชื่อที่มีเลข (Niño3.4, K1, AR(1), R², ω0) ไม่นับ
- ห้ามแต่งตัวเลข/ข้อเท็จจริงใหม่ ใช้ได้เฉพาะที่อยู่ใน facts.json และ claims ของหน้านั้น
- ห้ามมีป้ายหลักฐาน (หนักแน่น / งานเดียว / อนุมาน) บนจอ — ผู้นำเสนอบอกเอง · ป้ายชนิดภาพ gen_deck ใส่ให้
- ห้ามใช้สีส้มกับอะไรนอกจากอ่าวไทย · อันดามัน = `var(--andaman)` (น้ำเงิน) · อ่าวไทย = `var(--gulf)` (ส้ม)
- ถ้อยคำ: "สอดคล้องกับ" ไม่ใช่ "พิสูจน์" · อ่าวไทย = "ไม่พบสัญญาณที่ตรวจได้" · WNPMI ไม่ใช่ "ตัวเด่น" · ไม่โยงโลกร้อน

## ของที่มีให้ใช้

- class ใน `deck/style.css`: `.card` (การ์ดขาวมุมมน) · `.bubble` (ฟองข้อความทึบ) · `.pill` + `.real/.diag/.comp/.strong/.infer` ·
  `.andaman` `.gulf` `.muted` (สีข้อความ) · ตัวแปรสี `--ink --ink-2 --ink-3 --andaman --gulf --nino --dmi --event --card --shadow --radius`
- ฟอนต์: เนื้อความ Anuphan (ค่าเริ่มต้น) · ตัวเลขใหญ่/หัวการ์ด `font-family: 'Kanit'; font-weight: 500`
- `<SeriesChart>` — กราฟอนุกรมเวลาจากข้อมูลจริง (ดูหัวไฟล์ `deck/components/SeriesChart.vue`) · key ที่มี:
  `andaman_mm_12m` `gulf_mm_12m` `neg_nino34_12m` `neg_dmi_12m` (แกน t = ปี) · `x-range` ซูมช่วงได้
- `<FigCard src="/figs/<ชื่อ>.png" />` — รูปจากรายงาน (`00_input/report_figs/`) ในการ์ด · ใช้เป็นส่วนหนึ่งของหน้าได้
  (รูปต้องถูกคัดลอกไป `deck/public/figs/` — gen_deck คัดลอกเฉพาะรูปสำรองของหน้า ถ้าใช้รูปอื่นให้แจ้งในรายงาน)
- คลิก: `v-click="n"` บน element (n เริ่ม 1) · `<SeriesChart>` ใช้ `at` ต่อเส้น · ตัวเลขใน facts ที่เป็นลิสต์ใช้ `:index`
- CSS เฉพาะหน้า: ใส่ `<style>` ท้ายไฟล์หน้า (Slidev ทำให้มีผลเฉพาะหน้านั้น) · ตั้งชื่อ class ให้ไม่ซ้ำ (ขึ้นต้นด้วยรหัสหน้า เช่น `.s7-bars`)
- SVG inline วาดเองได้ (แผนภาพ ลูกศร กล่อง) — ข้อความใน `<text>` ที่มีตัวเลขก็ต้องผ่าน `<Fact/>`/`<Lit/>` ไม่ได้ → ใช้ HTML ทับแทน

## ขนาด (canvas 1920×1080)

หัวข้อใช้พื้นที่บนราว 230 px แล้ว เหลือพื้นที่เนื้อหาราว 1750 × 780 px · ข้อความเนื้อ 24 px · ป้าย/คำอธิบายเล็กสุด 20 px ·
ตัวเลขเด่น 54–90 px (Kanit) · ห้ามมีอะไรล้นการ์ดหรือล้นจอ

## ตรวจงานก่อนส่ง (ต้องทำ)

```bash
uv run python tools/deck_shots.py --name <ชื่อคุณ> --port <พอร์ตของคุณ> <รหัสหน้า> ...   # ภาพ renders/shots/<ชื่อ>/<รหัสหน้า>.png
uv run python tools/check_claims.py                                                     # ต้องจบด้วย ✅
```

เปิดดูภาพทุกหน้าด้วย Read แล้วแก้จนไม่มีอะไรล้น ทับกัน หรืออ่านยาก · `deck_shots` พิมพ์ "ok" ต่อหน้า — ไม่ ok = แก้
ภาพที่ถ่ายคือสภาพ **คลิกสุดท้าย** · ถ้าต้องการดูคลิกกลาง ๆ ให้ใส่ `<!-- clicks: N -->` ชั่วคราวไม่ได้ — แค่ตรวจว่าตำแหน่งไม่ทับกันในสภาพสุดท้ายก็พอ
