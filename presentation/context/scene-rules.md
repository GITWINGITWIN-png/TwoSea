# กฎของสไลด์ — อ่านก่อนเขียนหน้าใดทุกครั้ง (ทั้งคนและ subagent)

งานนี้คือ **deck สำหรับพูดสด ~15 นาที** ประกอบโครงงาน DSP — **ถูกต้องก่อนสวย** · คนพูดคุมจังหวะด้วยการคลิก
สเปกของทุกหน้าอยู่ใน `context/script.md` (หน้าละหัวข้อ `### SQnn_Snnn`: `หัวข้อ:` · `ภาพ:` · `ขั้น:` · `พูด:`)

## โครงไฟล์

- หนึ่งตอน = หนึ่งไฟล์ `manim/sqNN_<slug>.py` = หนึ่ง class (`class SQ03(DeckSlide)`) — มีอยู่แล้ว
- **หนึ่งหน้า = หนึ่ง method ชื่อรหัสหน้าตัวเล็ก** (`def sq03_s030(self):`) — หน้าที่ยังไม่มี method เป็นภาพสำรองอัตโนมัติ
- ใน method:
  ```python
  def sq03_s030(self):
      page = self.slide("SQ03_S030")          # คลิกแรก: ล้างหน้าก่อน + หัวข้อ + ป้าย + เลขหน้า + โน้ต (ห้ามวางเอง)
      center, w, h = page["box"]              # พื้นที่เนื้อหาใต้หัวข้อ — วางทุกอย่างในนี้
      self.play(Create(axes), run_time=1.5)   # ขั้นที่ 1 ตามบรรทัด "ขั้น: 1."
      self.click()                            # คลิก = ขั้นถัดไป ("ขั้น: 2.")
      self.play(...)
      self.summary("…")                       # ถ้าบทมี "การ์ดสรุป:" — ข้อความตามบทตรงตัว (เป็นคลิกของมันเอง)
  ```
- **จำนวน `slide()` + `click()` + `summary()` ของหน้า = จำนวนบรรทัดใน `ขั้น:`** (การ์ดสรุปนับเป็นขั้นตามบท)
- ภาพเคลื่อนต่อเนื่อง (Morlet เลื่อน ลมพัด): `self.slide(..., loop=True)` หรือ `self.click(loop=True)` แล้ว `play` หนึ่งรอบที่จบตรงจุดเริ่ม
- ซ่อนเฉลยก่อนจุดทาย: `self.slide(id, headline_text="ส่วนแรกของหัวข้อ")` แล้วตอนเฉลย `Transform` เป็น `headline(page_text)` จาก slides_kit
- ใช้ของใน toolkit: `slides_kit` (`headline`, `figure`, `content_box`) · `plots` (`Frame2D`, `series_line`, `series_fill`, `wtc_plane`,
  `colorbar`, `wtc_key`, `legend`, `period_ticks`) · `studio_style` (สี ฟอนต์ ป้าย) · `facts` (`F`, `num`, `derived`, `processed`)

## จังหวะ (พูดสด ไม่มีเสียงบรรยาย)

- **แต่ละขั้นเคลื่อน ≤ ~2.5 วินาที แล้วจบนิ่ง** — คนพูดพูดทับภาพที่ค้าง ไม่ต้องรอภาพ · ไม่มี `wait` ยาว
- ขั้นแรกของหน้า: หัวข้อขึ้นแล้ว (slide() วางให้) → เคลื่อนแค่เนื้อหา
- จบหน้าด้วยภาพที่ครบสมบูรณ์ (เฟรมสุดท้ายคือหน้าใน PDF ที่ส่งอาจารย์)

## ความถูกต้อง (ห้ามข้าม)

- **ตัวเลขบนจอมาจาก `facts.py` เท่านั้น**: `thai(f"... {num('season.share_gulf')}%")` — `check_claims.py` จะ fail ถ้าเจอเลขพิมพ์เองใน `thai("...")`
  (ปีบนแกนและขีดแกนสร้างจากข้อมูลได้) · **ข้อมูลจริงมาจาก loader ใน facts.py เท่านั้น** — ห้ามแต่งข้อมูล
- ภาพตัวอย่าง/แผนภาพที่ไม่ใช่ข้อมูลจริง (คลื่นตัวอย่าง, Morlet, แอ่งน้ำ) ใช้ข้อมูลสังเคราะห์ได้ เพราะหน้านั้นมีป้าย "แผนภาพ" อยู่แล้ว
  แต่ห้ามแสดงตัวเลขผลลัพธ์จากข้อมูลสังเคราะห์
- ถ้อยคำบนจอเพิ่มจากหัวข้อได้แค่ **ป้ายสั้น ๆ ที่มีอยู่ในบรรทัด `ภาพ:`** (ชื่อแกน, ชื่อดัชนี, ป้ายเหตุการณ์) — ห้ามเติมข้อเท็จจริงใหม่
- ถ้อยคำ: "สอดคล้องกับ" ไม่ใช่ "พิสูจน์" · coherence ≠ เหตุและผล · อ่าวไทย = "ไม่พบสัญญาณที่ตรวจได้" · WNPMI ไม่ใช่ "ตัวเด่น"
- กราฟมีแกน + หน่วยเสมอ · ระนาบ WTC มี COI (เส้นประ) + เส้นเกณฑ์ 95% (ขาว) เสมอ · colormap viridis
