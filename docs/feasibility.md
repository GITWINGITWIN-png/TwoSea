### L6 — ✅ ผ่าน แต่ต้องอ่านข้อควรระวังนี้

map ทักษะทีละขั้นของทาง C เข้ากับซิลลาบัส:

| ขั้นของไปป์ไลน์ | บทในวิชา |
| --- | --- |
| จัดการ missing 3.1% · สัญญาณสุ่ม · surrogate | ✅ บทที่ 1 (random signals) |
| **anti-alias LPF + decimation รายชั่วโมง → รายปี** | ✅✅ **บทที่ 3 (multirate) + บทที่ 4 (FIR/IIR)** |
| cross-spectrum · coherence · PASC/AWC | ✅ **บทที่ 2** — coherence คือ correlogram/cross-spectrum ในรูปหลายตัวแปร |
| **AR(1) fitting สำหรับ null hypothesis** | ✅ **บทที่ 5 (parametric estimation)** |
| CWT (Morlet) เอง | ⚠️ **ดูข้อควรระวัง** |

> [!warning] ⚠️ ข้อควรระวังที่ต้องพูด — **ซิลลาบัสไม่มีคำว่า wavelet**
> บทที่ 2 ระบุ **DFT · circular convolution · FFT · Goertzel · Chirp-Z · correlogram ·
> periodogram** ส่วนบทที่ 3 คือ **multirate + filter bank** — **CWT/Morlet ไม่ได้ถูกระบุชื่อ
> ในบทไหนเลย** มันเป็นเครื่องมือที่*อยู่ข้าง ๆ* เนื้อวิชา ไม่ใช่*อยู่ใน*เนื้อวิชา
>
> **ทำไมถึงยังตัดสินว่าผ่าน:** เพราะภายใต้ทาง C **แกนหลักของงานคือชั้นที่วิชาสอน**
> (decimation, FIR/IIR, cross-spectrum, AR estimation) ส่วน wavelet เป็น*พาหนะ*
> และ DWT/filter-bank เชื่อมกับบทที่ 3 โดยตรง
>
> **ทำไมทาง B ถึงตก:** ถ้าเรียก `pycwt.wct()` กับ `vectorwavelet::mwc()` แล้วจบ
> สิ่งที่เหลือให้วิชาให้คะแนนคือ **ศูนย์** — งานจะกลายเป็นการวิเคราะห์ภูมิอากาศ
> ที่บังเอิญใช้เครื่องมือของคนอื่น นี่คือกับดักเดียวกับที่ `fit-to-purpose.md` บันทึกไว้
> จากเคส dengue เป๊ะ ๆ
>
> **ถ้าอยากลดความเสี่ยงข้อนี้ให้เหลือศูนย์:** เพิ่ม MODWT/filter-bank เป็นทางเลือกที่สอง
> ของการทำ multiscale decomposition แล้วเทียบกับ CWT — จะได้ทั้ง "filter bank" ที่ระบุ
> ชื่อในบทที่ 3 ตรง ๆ **แต่กิน slack เพิ่ม ~3 effort-day (เหลือ +6 วัน)**

### 🔴 Wavelet coherence จริง เทียบกับ AR(1) surrogate

```
                     coherence แถบ 2–7 ปี    null (AR(1), 60 ชุด)          p
```

**อ่านผลนี้ยังไง**

1. **premise test ผ่าน** — ไปป์ไลน์ดึงสัญญาณที่รู้ว่ามีอยู่ออกมาได้จริง **ที่สถานีอันดามัน**
2. 🔴 **รายงานฉบับแรกของผมระบุ premise test ให้ใช้ Ko Lak ซึ่งเป็นสถานีที่ไม่มีสัญญาณ**
   ถ้าทำตามนั้นจะได้ผลว่าง แล้วสรุปผิดว่าโค้ดตัวเองพัง **แก้เป็น Ko Taphao Noi แล้ว**
3. **นี่คือข้อค้นพบตั้งต้นของโปรเจกต์เอง** — สองทะเลของไทยตอบสนอง ENSO ต่างกันคนละเรื่อง
   อ่าวไทยถูกครอบงำด้วยมรสุม (วงรอบปีอธิบาย 80% ของความแปรปรวน) ส่วนอันดามันเปิดรับ ENSO
   ตรงกับที่เปเปอร์ต้นทางเรียกว่า *"differences among places"* พอดี

### สิ่งที่การรันครั้งนี้ **ยังไม่ได้พิสูจน์** — อย่าอ่านเกินกว่านี้

- **เติมช่องว่างด้วย linear interpolation แบบหยาบ** ทั้งที่ค่าหาย 2.6–6.2% และปี 2004
  หายทั้งสามสถานี — ของจริงต้องจัดการดีกว่านี้ และผลอาจขยับ
- ใช้ **coherence เฉลี่ยทั้งแถบ** เป็นสถิติ ส่วนเปเปอร์ต้นทางใช้ **PASC** (สัดส่วนพื้นที่
  ที่มีนัยสำคัญ*เฉพาะจุด*) ซึ่งต้องทำ significance รายจุด — **งานหนักกว่านี้มาก**
- surrogate แค่ **60 ชุด** (ของจริงควร ≥1000) · `dj=1/6` หยาบกว่าที่ควรใช้
- ใช้ `pycwt` 0.5.0b0 ซึ่งเป็น **beta** · **และนี่คือการรันแบบทาง B** (เรียกไลบรารี)
  ซึ่ง**ไม่ใช่โปรเจกต์** มันแค่พิสูจน์ว่าข้อมูลกับสมมติฐานไม่ตายเท่านั้น
- **ยังไม่ได้แตะ MWC เลยแม้แต่นิดเดียว** ซึ่งเป็นหัวใจของเปเปอร์และเป็นส่วนที่ไม่มีใน Python

### ความเสี่ยงใหม่ที่ผลนี้เปิดออกมา

**ถ้า Ko Lak ไม่มีสัญญาณ ENSO เลย การรวมดัชนีหลายตัว (MWC) ที่สถานีนั้นก็อาจไม่เจออะไร
เหมือนกัน** — ซึ่ง**ไม่ใช่เหตุให้หยุด** ตามที่คุณระบุไว้เองว่ายอมรับผลลบ แต่ต้องรู้ล่วงหน้า
ว่าเรื่องเล่าของรายงานอาจกลายเป็น *"อ่าวไทยอธิบายด้วยดัชนีภูมิอากาศไม่ได้ ต่างจากอันดามัน"*
แทนที่จะเป็น *"ต้องใช้ 3–5 ดัชนีเหมือนอเมริกาเหนือ"* — **นั่นยังเป็นคำตอบที่มีค่า**

## 🎯 Premise test — ทำให้จบภายใน 2026-09-16

**สิ่งที่การรันเบื้องต้นทำไปแล้วคือครึ่งเดียว: มันพิสูจน์ว่า*ข้อมูลและสมมติฐาน*ไม่ตาย
แต่ยังไม่พิสูจน์ว่า*คุณเขียนโค้ดชั้นนั้นเองได้ทัน* ซึ่งคือ L4 ลิงก์ที่อ่อนที่สุด**

> **การทดลอง:** เขียน cross-wavelet spectrum + wavelet coherence ด้วยมือ (ใช้ `pycwt.cwt`
> เป็นฐานได้ แต่ห้ามใช้ `pycwt.wct`) แล้วรันระหว่าง **KO TAPHAO NOI (PSMSL 446, รายเดือน)**
> กับ **Niño3.4** พร้อม AR(1) surrogate ของคุณเอง — **แล้วดูว่าได้ p ใกล้เคียง 0.016
> ที่ผมได้จากไลบรารีไหม**

**นี่คือ premise test ที่ดีกว่าเดิม เพราะตอนนี้มีเลขเป้าให้เทียบแล้ว** ไม่ใช่แค่
"ดูว่าแถบโผล่ไหม" — คุณกำลังตรวจโค้ดตัวเองกับ implementation ที่มีคนใช้จริง 351 ดาว

**เกณฑ์ที่แปลว่าให้เลิก:**
- ถึง **2026-09-16** แล้วยังไม่มี coherence ที่คุณเขียนเองรันได้ → หนี้ทักษะ L4 สูงกว่าที่
  ประเมิน ทาง C ไม่ทัน **ให้ถอยไปทาง B แล้วเปลี่ยนที่ส่ง หรือหยุด** ไม่ใช่ดันต่อ
- โค้ดของคุณให้ค่า coherence ต่างจาก `pycwt.wct` **เกิน ~0.05 ในแถบ 2–7 ปี** และหา
  สาเหตุไม่เจอภายในสัปดาห์นั้น → มีบั๊กที่ยังจับไม่ได้ **หยุด**

*(ถ้าเลขต่างกันเล็กน้อยเพราะ smoothing operator คนละสูตร — นั่นไม่ใช่เหตุให้หยุด
นั่นคือสิ่งที่ต้องเขียนอธิบายในรายงาน)*
