## 1. คำถาม

### ทำไมถาม

- **สัญญาณที่สนใจ** ระดับน้ำทะเลรายเดือนประกอบด้วยสามส่วนซ้อนกัน คือ (1) วงรอบฤดูกาล (2) **ความผันแปรระหว่างปี** คือการขึ้นลงที่กินเวลาข้ามปี เช่น น้ำต่ำกว่าปกติทั้งปีในช่วง El Niño และ (3) **แนวโน้มระยะยาว** คือการเพิ่มหรือลดต่อเนื่องหลายสิบปี เช่น น้ำทะเลสูงขึ้นจากภาวะโลกร้อนหรือแผ่นดินทรุด งานนี้ศึกษาเฉพาะส่วนที่ (2) จึงตัดส่วนที่ (1) และ (3) ออกก่อน
- **ทำไมต้องใช้เวฟเล็ต** ความสัมพันธ์ระหว่างปี "เปิด" เฉพาะช่วงที่เกิดเหตุการณ์ภูมิอากาศ และแทบหายไปในปีปกติ ค่าสหสัมพันธ์ที่เฉลี่ยทั้งอนุกรมจึงจับไม่ได้ (ในงานนี้ $r$ กับ −DMI = 0.10 ทั้งที่ coherence มีนัยสำคัญ) การแปลงเวฟเล็ตบอกได้ว่าสัมพันธ์ **เมื่อไรและที่คาบใด** (Torrence & Compo, 1998)
- **ช่องว่างจากงานต้นทาง** Song และ Chen (2022) ใช้ WTC + MWC กับมาตรวัด 82 สถานีในอเมริกาเหนือ และพบว่า PASC เพิ่มจาก 14% เป็น 96% ตามจำนวนดัชนีที่รวม แต่ไม่ได้ระบุว่าปรับเกณฑ์นัยสำคัญตามจำนวนดัชนีหรือไม่ และไม่มีดัชนีมหาสมุทรอินเดียหรือมรสุมในชุดที่ใช้
- **การทดลองธรรมชาติ** ประเทศไทยมีสองทะเลที่อยู่ห่างกันไม่ถึง 450 กม. แต่ต่างกันมาก คือทะเลอันดามันซึ่งลึกและเปิดสู่มหาสมุทรอินเดีย กับอ่าวไทยซึ่งตื้นและเกือบปิด (รูปที่ 1)

**ขั้นที่ 1 เตรียมสัญญาณ**
- ตัดค่าผิดปกติสองเดือน (ต.ค. 1985, มิ.ย. 1987) ซึ่งสูงกว่าเดือนข้างเคียง ~255 มม. โดยข้อมูล UHSLC ช่วงเดียวกันไม่มีค่านี้
- ตัดแนวโน้มเชิงเส้นและฮาร์มอนิกรายปี/ครึ่งปี โดยประมาณค่าจากเดือนที่มีข้อมูลจริงเท่านั้น — จำเป็นเพราะฤดูกาลอธิบายความแปรปรวนที่เกาะหลักได้ถึง **ร้อยละ 81** (แอมพลิจูด 213 มม.) เทียบกับร้อยละ 30 ที่เกาะตะเภาน้อย (87 มม.) ถ้าไม่ตัดจะเห็นแต่ฤดูกาล
- ช่องว่าง ≤ 3 เดือนประมาณค่าในช่วงเชิงเส้น ที่ยาวกว่าเติมศูนย์ และบันทึกตำแหน่งไว้ในหน้ากาก จุดบนระนาบที่หน้าต่างปรับเรียบมีค่าเติมเกินร้อยละ 50 จะไม่นับ

**ขั้นที่ 2 กรองก่อนลดอัตราสุ่ม** ข้อมูลรายชั่วโมง UHSLC (1985–2019) → รายวัน → รายเดือน ผ่านตัวกรองกันการพับความถี่ FIR หน้าต่าง Kaiser 261 แท็ป ลดทอนแถบหยุด 70 dB ($\beta = 6.7553$) — ถ้าไม่กรอง องค์ประกอบน้ำขึ้นน้ำลง (M2, S2, K1, O1 …) จะพับลงมาที่ความถี่ต่ำ

**ขั้นที่ 3 WTC และ MWC** ใช้ CWT เวฟเล็ต Morlet ($\omega_0 = 6$) 12 สเกลต่อออกเทฟ นับเฉพาะบริเวณในกรวยอิทธิพล (COI) ที่ไม่ได้รับผลจากขอบข้อมูล

$$
R^2(s,\tau)=\frac{\left|S\!\left(s^{-1}W_{XY}\right)\right|^2}{S\!\left(s^{-1}|W_X|^2\right)\,S\!\left(s^{-1}|W_Y|^2\right)}
\qquad
\rho^2(s,\tau)=\frac{\widetilde{W}_{YX}\,\widetilde{W}_{XX}^{-1}\,\widetilde{W}_{YX}^{H}}{\widetilde{W}_{YY}}
$$

- $R^2$ (WTC; Grinsted et al., 2004) คือ "สหสัมพันธ์กำลังสองเฉพาะที่" ระหว่างดัชนี $X$ กับระดับน้ำ $Y$ ณ เวลา $\tau$ คาบ $s$ ค่า 0–1 · $S(\cdot)$ คือการปรับเรียบในทิศเวลาและสเกล
- $\rho^2$ (MWC; Hu & Si, 2016) ขยายเป็น $q$ ดัชนีพร้อมกัน ($\widetilde{W}_{XX}$ เป็นเมทริกซ์ $q\times q$) เมื่อ $q = 1$ ได้ $R^2$
- **มุมเฟส** $\theta = \varphi_{\text{ระดับน้ำ}} - \varphi_{\text{ดัชนี}}$ · 0° = ขึ้นลงไปด้วยกัน · 180° = สวนทาง · มุมระหว่างนั้นบอกว่าใครนำ/ตาม
- **PASC** (ตัวชี้วัดหลัก) = ร้อยละของพื้นที่ใน COI ที่ $R^2$ หรือ $\rho^2$ เกินเกณฑ์ 95% · รายงานทั้งระนาบ และเฉพาะแถบคาบ 2–7 ปี (แถบหลักของ ENSO)
- MWC คำนวณทุกชุดขนาด 1–5 ตัวจากดัชนีแปดตัว = **218 ชุด** · หยุดที่ 5 ตัวตามงานต้นทาง และเพราะที่ $q = 5$ เกณฑ์นัยสำคัญขึ้นไปถึง 0.96 แล้ว (หัวข้อ 4.3) หากเพิ่มอีก เกณฑ์จะเข้าใกล้ 1 จนแทบไม่มีจุดใดผ่านได้

**ขั้นที่ 4 ทดสอบนัยสำคัญ** เกณฑ์ 95% จากอนุกรมสุ่ม AR(1) 1,000 ชุดต่อกรณี (อัตสหสัมพันธ์เท่าข้อมูลจริง) และเพิ่มสามขั้นที่งานต้นทางไม่ได้ทำ

| ขั้นที่เพิ่ม | ทำไมต้องมี |
| --- | --- |
| **เกณฑ์แยกตามจำนวนดัชนี $q$** (จำลอง AR(1) อิสระ $q+1$ อนุกรม) | $\rho^2$ ของสัญญาณรบกวนสูงขึ้นเองเมื่อ $q$ เพิ่ม |
| **ค่า p ของ PASC** (เทียบกับการแจกแจง PASC ของสัญญาณรบกวน) | จุดข้างเคียงสัมพันธ์กันจากการปรับเรียบ สัญญาณรบกวนจึงเกินเกณฑ์เป็นก้อน (Maraun & Kurths, 2004) — PASC ของสัญญาณรบกวนเฉลี่ย ~5% แต่ควอนไทล์ 95 อยู่ที่ **~9%** (ทั้งระนาบ) และ 13–15% (แถบ 2–7 ปี) |

## 4. คำตอบ

### 4.1 สองฝั่งตอบสนองต่างกันหรือไม่

**คำตอบ: ต่างกันชัดเจน** ฝั่งอันดามันสัมพันธ์กับดัชนีสี่ตัว ฝั่งอ่าวไทยไม่สัมพันธ์กับดัชนีใดเลย ทั้งสองข้อคงอยู่ครบ 8/8 แบบทดสอบ

**หลักฐาน**
- **อันดามัน (เกาะตะเภาน้อย)** PASC ทั้งระนาบ: SOI 14.3%, DMI 13.6%, WNPMI 13.3%, Niño3.4 10.0% เทียบกับระดับสัญญาณรบกวน ~9% · แถบ 2–7 ปี: WNPMI 32.2%, DMI 17.7%, SOI 16.1% (รูปที่ 5)
- **อ่าวไทย (เกาะหลัก)** ไม่มีดัชนีใดเกินระดับสัญญาณรบกวน (~8–9%) ค่าสูงสุดคือ NAO 6.5% และ AMO 6.4% ส่วนกลุ่ม ENSO ได้เพียง 2.5–4.8% · ค่า p ทั้งตระกูลจากการค้นหา MWC 218 ชุดอยู่ที่ 0.29–0.59 · บริเวณ coherence กระจายเป็นจุดเล็กไม่ต่อเนื่อง เหมือนที่สัญญาณรบกวนสร้างได้ (รูปที่ 6 แถวล่าง)
  - ข้อยกเว้นเดียว: แบบ V5 มีชุดหลายดัชนีสองชุดผ่าน แต่ไม่ปรากฏใน V6 ซึ่งเป็นช่วงเวลาเดียวกันจากอีกคลังข้อมูล จึงไม่นับ
- **ดัชนีอื่น** AMO ผ่านในแถบ 2–7 ปี (13.9%) แต่คงอยู่เพียง 4/7 แบบและไม่มีกลไกรองรับ จึงไม่นับ · PDO, TPI, NAO ไม่ผ่าน · แถบ 8–16 ปีสรุปไม่ได้ เพราะสัญญาณรบกวนล้วนก็ให้ PASC 22–30% แล้ว
- **เกิดเป็นช่วง ๆ** ความสัมพันธ์ฝั่งอันดามันรวมตัวช่วงปลายทศวรรษ 1990–2000 ที่คาบ 2–5 ปี เหตุการณ์ใหญ่สุดคือ 1997–98 ที่ระดับน้ำ (เฉลี่ย 12 เดือน) ลดลง ~210 มม. ตรงกับรายงานภาคสนามว่าน้ำที่ภูเก็ตต่ำกว่าปกติ ~29 ซม. นาน 7 เดือนจนปะการังตาย (Brown et al., 2019) และ ทช. บันทึกน้ำลงต่ำผิดปกติฝั่งอันดามันในปี 1997, 2006, 2019 ซึ่งล้วนเป็นปี IOD บวก (นิพนธ์ พงศ์สุวรรณ, 2564) — แต่สหสัมพันธ์ทั้งอนุกรมได้เพียง $r$ = 0.30 (−Niño3.4) และ 0.10 (−DMI) (รูปที่ 7)

**รูปที่ 5** PASC ของดัชนีเดี่ยว สองสถานี × สองช่วงคาบ ระบายสีเฉพาะช่องที่มีนัยสำคัญ (p < 0.05) ตัวเลขคือจำนวนแบบทดสอบที่ยังผ่าน (AMO มี 7 แบบเพราะถูกตัดใน V4)

**รูปที่ 6** ระนาบ WTC ของเกาะตะเภาน้อย (บน) และเกาะหลัก (ล่าง) กับดัชนีสามตัว เส้นขาว = เกินเกณฑ์ 95% · เส้นประ = COI · ลูกศรขวา = ไปด้วยกัน · ซ้าย = สวนทาง · ชี้ขึ้น = ระดับน้ำนำ

**รูปที่ 7** ระดับน้ำระหว่างปี (เฉลี่ย 12 เดือน) เทียบกับ −Niño3.4 และ −DMI (กลับเครื่องหมายให้ดัชนีขึ้น = น้ำลง) ป้ายคือปีที่หน่วยงานไทยบันทึกน้ำลงต่ำผิดปกติ ค่า $r$ ใช้บรรยายเท่านั้น

**เพราะอะไรอ่าวไทยจึงไม่สัมพันธ์** — ไม่ใช่วิธีล้มเหลว แต่ตรงกับลักษณะทางกายภาพของอ่าว
- **ตื้นและตอบสนองทันที** ลึกเฉลี่ย ~40 ม. ระดับน้ำทั้งแอ่งแปรตาม curl ของลมที่ $r = -0.84$ โดยไม่มีความหน่วง จึงไม่สะสมสัญญาณข้ามปี (Anutaliya, 2023) *(หลายงานรองรับ)*
- **ฤดูกาลกลบ** มรสุมตะวันออกเฉียงเหนือดันน้ำเข้าอ่าว วงรอบรายปี ~20 ซม. (Wouters & Chambers, 2010) ตรงกับ 213 มม. / ร้อยละ 81 ที่วัดได้ *(หลายงานรองรับ)*
- **อยู่นอกเส้นทางคลื่น** สัญญาณ ENSO ทางมหาสมุทรเข้าทะเลจีนใต้ทางช่องแคบลูซอน ส่วนไหล่ทวีปซุนดาตอนใต้ไม่สัมพันธ์กับ Niño3.4 (Liu et al., 2011) *(หลายงานรองรับ)* และช่องแคบมะละกาตื้นเกินกว่าจะส่งคลื่นจากอันดามันมาได้ *(อนุมาน)*
- **สัญญาณเล็ก** ENSO ปรับระดับน้ำชายฝั่งตะวันออกของคาบสมุทรมลายูเพียง ±3–5 ซม. (Luu et al., 2015) ใกล้เคียงกับความแปรปรวนของฤดูกาลเอง *(งานเดียว)*
- สอดคล้องกับที่หน่วยงานรัฐอธิบายน้ำทะเลหนุนสูงในอ่าวไทยว่ามาจากน้ำเกิด มรสุม และน้ำท่า โดยไม่โยงกับ ENSO (กรมประชาสัมพันธ์, 2568)

ส่วนเหตุผลที่ฝั่งอันดามันสัมพันธ์ อธิบายพร้อมกับทิศของความสัมพันธ์ในหัวข้อ 4.2

### 4.2 ดัชนีใดสำคัญ และสัมพันธ์ในทิศใด

**คำตอบ:** SOI, Niño3.4, DMI และ WNPMI **ไม่ใช่ตัวขับสี่ตัวที่แยกกัน แต่สะท้อนระบบ ENSO–IOD เดียวกัน** ที่ส่งผลผ่านลมเหนือเส้นศูนย์สูตรมหาสมุทรอินเดีย หลักฐานคือ **ทิศของความสัมพันธ์ตรงกับที่ทำนายจากกลไกไว้ก่อนดูผลครบทั้งสี่ดัชนี** ส่วนลำดับว่าตัวใดเด่นที่สุดยังสรุปไม่ได้ (หัวข้อ 4.4)

**หลักฐาน** มุมเฟสเฉลี่ยเชิงวงกลมในบริเวณที่มีนัยสำคัญ แถบ 2–7 ปี ($R$ = ความสม่ำเสมอของทิศ, 1 = ทุกจุดทิศเดียวกัน)

| ดัชนี | $\theta$ ที่วัดได้ ($R$) | ที่ทำนายไว้ | ความหมาย |
| --- | --- | --- | --- |
| SOI | −28° (0.96) | ≈ 0° | ✓ ไปด้วยกัน ระดับน้ำตาม ~3 เดือน |
| Niño3.4 | +156° (0.92) | ≈ 180° | ✓ สวนทาง ระดับน้ำตาม ~3 เดือน (สอดคล้องกับ SOI) |
| DMI | −150° (0.55) | ≈ 180° | ✓ สวนทาง ระดับน้ำลดก่อน DMI สูงสุด ~5 เดือน · ทิศกระจายกว่าตัวอื่น |
| WNPMI | +56° (0.97) | 0…+60° (อนุมาน) | ✓ ไปด้วยกัน ระดับน้ำ **นำ** ~6 เดือน |

![รูปที่ 8](../../figures/report/fig12_phase.png)

**รูปที่ 8** มุมเฟสของเกาะตะเภาน้อยกับดัชนีสี่ตัว (แถบ 2–7 ปี บริเวณมีนัยสำคัญ) ลูกศรดำ = ทิศเฉลี่ย · แรเงา = ช่วงที่ทำนายไว้ก่อน (ลายเส้น = ได้จากการอนุมาน) · แท่งเทา = การแจกแจงทุกจุด

**เพราะอะไร** ลำดับกลไกในปีที่เกิด El Niño หรือ IOD บวก (รูปที่ 9)
1. การไหลเวียนวอล์กเกอร์เลื่อน อากาศจมเหนือภูมิภาคทะเลทวีป เกิดลมตะวันออกผิดปกตินอกชวา–สุมาตรา ซึ่งเป็นลมแบบเดียวกับที่กระตุ้น IOD บวก ⇒ สัญญาณ ENSO มาถึงอันดามัน **ทางบรรยากาศ** ไม่ใช่ทางทะเลผ่านอินโดนีเซีย (Ashok et al., 2003) *(หลายงานรองรับ)*
2. ลมตะวันออกผิดปกติกระตุ้นคลื่นเคลวินแบบยกเทอร์โมไคลน์ แพร่ไปตะวันออกตามเส้นศูนย์สูตร *(หลายงานรองรับ)*
3. ถึงสุมาตรากลายเป็นคลื่นเคลวินชายฝั่ง แพร่ทวนเข็มนาฬิการอบอ่าวเบงกอลผ่านอันดามัน — ในแบบจำลอง ลมเหนือเส้นศูนย์สูตรอย่างเดียวอธิบายระดับน้ำขอบตะวันออกอ่าวเบงกอลได้ $r = 0.95$ ขณะที่ลมท้องถิ่นได้เพียง 0.28 (Han & Webster, 2002) *(หลายงานรองรับ)* · คลื่นเดินทางสุมาตรา→ภูเก็ตไม่ถึงสองสัปดาห์ สั้นกว่าความละเอียดรายเดือน *(อนุมาน)*
4. ⇒ ทั้ง El Niño และ IOD บวกทำให้น้ำที่ภูเก็ต **ลดลง** ตรงกับมุม ≈180° ของ Niño3.4/DMI และ ≈0° ของ SOI

![รูปที่ 9](../../figures/report/map03_mechanism.png)

**รูปที่ 9** ลำดับกลไกในปี El Niño / IOD บวก (ปีตรงข้ามลูกศรกลับทิศทั้งหมด) เรียบเรียงจาก Han & Webster (2002), Rao et al. (2010), Aparna et al. (2012), Brown et al. (2019), Anutaliya (2023), นิพนธ์ พงศ์สุวรรณ (2564)

กลไกเดียวนี้อธิบายผลสามข้อพร้อมกัน: (1) ดัชนีสี่ตัวผ่านพร้อมกันเพราะวัดระบบเดียวกัน (2) รวมหลายดัชนีแล้วไม่ช่วย เพราะทุกตัวผ่านตัวกลางเดียวกัน (หัวข้อ 4.3) (3) อ่าวไทยอยู่นอกเส้นทางคลื่น (หัวข้อ 4.1)

ข้อสังเกตเพิ่ม
- DMI: ระดับน้ำอ่าวเบงกอลเริ่มลดตั้งแต่เมษายน ขณะที่ IOD สูงสุดกันยายน–พฤศจิกายน (Aparna et al., 2012) จึงเห็นระดับน้ำ "นำ" DMI *(งานเดียว)*
- WNPMI: ระดับน้ำนำ ~6 เดือน ตรงกับที่มรสุมแปซิฟิกตะวันตกเฉียงเหนืออ่อนกำลังในฤดูร้อน **หลัง** ปี El Niño (Wang et al., 2001) ⇒ WNPMI น่าจะเป็นผลตามของ ENSO มากกว่าตัวขับระดับน้ำ *(อนุมาน)*

### 4.3 รวมหลายดัชนีช่วยหรือไม่

**คำตอบ: ไม่ช่วย ดัชนีเดี่ยวเพียงพอ** และ PASC ที่พุ่งขึ้นตามจำนวนดัชนี (แบบที่งานต้นทางรายงาน) เกิดได้จากสัญญาณรบกวนล้วนถ้าใช้เกณฑ์เดียวกับทุก $q$

**หลักฐาน**
- **เกณฑ์ต้องสูงขึ้นตาม $q$** เกณฑ์ 95% ของ $\rho^2$ (กึ่งกลางแกนสเกล) = 0.59, 0.77, 0.87, 0.93, 0.96 ที่ $q$ = 1–5 เพราะหลังปรับเรียบ (Grinsted et al., 2004) ในหน้าต่างเหลือข้อมูลอิสระเพียง ~4–6 ค่า ใกล้เคียงกับจำนวนดัชนี (รูปที่ 10)
- **ทดลองกับดัชนีปลอม** รันกระบวนการเดิมกับดัชนีสุ่ม AR(1) แปดตัว (รูปที่ 11)
  - ไม่ปรับเกณฑ์: PASC ดัชนีปลอม = 4.8 → 25.7 → 59.8 → 86.4 → 97.2% รูปแบบเดียวกับ Song & Chen (14 → 50 → 81 → 96%) และดัชนีจริงของเกาะตะเภาน้อย (9.3 → 98.5%) **แยกไม่ออกจากดัชนีปลอม**
  - ปรับเกณฑ์ตาม $q$: ดัชนีปลอมคงที่ ~4.7% ทุก $q$ (ตรงกับระดับนัยสำคัญ 5%) ส่วนดัชนีจริงอยู่ที่ 9–10%
- **ชุดที่ดีที่สุดไม่ดีกว่าดัชนีเดี่ยว** (เกณฑ์ปรับแล้ว ค้นครบ 218 ชุด) ส่วนเพิ่มสูงสุด 0.6 จุดร้อยละ (ทั้งระนาบ) และ ≤ 0 (แถบ 2–7 ปี) ต่ำกว่าเกณฑ์ 5 จุดร้อยละ (Hu et al., 2017) ที่ตั้งไว้ล่วงหน้า (รูปที่ 12)
  - ชุดที่ดีที่สุด: ทั้งระนาบ = SOI (14.3%, p ทั้งตระกูล = 0.03) · แถบ 2–7 ปี = WNPMI (32.2%, p ทั้งตระกูล = 0.005)
- **ต้องควบคุมการเปรียบเทียบเชิงซ้อน** 136 จาก 218 ชุดมี p รายชุด < 0.05 แต่มีเพียง 4–5 ชุดที่ p ทั้งตระกูล < 0.05
- **ดัชนีประจำภูมิภาค (DMI, WNPMI) ช่วยหรือไม่** แถบ 2–7 ปี ชุดดีที่สุดจาก 8 ดัชนีสูงกว่าจาก 6 ดัชนีของงานต้นทาง 11.2 จุดร้อยละ (p = 0.022) แต่ทั้งระนาบต่างเพียง 0.8 (p = 0.43) และคงอยู่แค่ 4/8 แบบ ⇒ **เป็นเพียงแนวโน้ม**

![รูปที่ 10](../../figures/report/fig05_threshold_vs_q.png)

**รูปที่ 10** เกณฑ์ 95% ของ MWC ตามคาบ สำหรับ $q$ = 1–5 (เส้นสามสถานีแทบทับกัน) แถบเทา = คาบ 2–7 ปี

![รูปที่ 11](../../figures/report/fig06_q6_false_floor.png)

**รูปที่ 11** PASC เฉลี่ยของทุกชุดขนาด $q$ ดัชนีจริงเทียบดัชนีปลอม ไม่ปรับเกณฑ์ (แดง) และปรับตาม $q$ (น้ำเงิน) สามเหลี่ยม = ค่าที่ Song & Chen (2022) รายงาน

![รูปที่ 12](../../figures/report/fig07_q3_best_per_q.png)

**รูปที่ 12** PASC ของชุดดีที่สุดในแต่ละ $q$ เทียบกับการแจกแจงค่าสูงสุดของการค้นหาบนระดับน้ำสุ่ม 1,000 ชุด ป้าย = ชุดดัชนีที่ได้ค่าสูงสุด

**เพราะอะไร**
- **ทางกายภาพ** ทุกดัชนีส่งผลผ่านเส้นทางลมเดียวกัน และ ENSO กับ IOD มักเกิดร่วมกัน ดัชนีที่เพิ่มเข้าไปจึงซ้ำซ้อน *(หลายงานรองรับ)*
- **ทางสถิติ** เมื่อจำนวนดัชนีเข้าใกล้จำนวนข้อมูลอิสระในหน้าต่าง $\rho^2$ ก็สูงขึ้นได้เองแม้ไม่มีความสัมพันธ์ — เหมือน $R^2$ ของการถดถอยที่เพิ่มขึ้นเสมอเมื่อเพิ่มตัวแปร
- ข้อสังเกตต่องานต้นทาง: AWC ต่ำสุดของชุด 5 ดัชนีที่ Song & Chen รายงาน (0.938) ต่ำกว่าเกณฑ์ $q = 5$ ที่งานนี้วัดได้ภายใต้การปรับเรียบแบบเดียวกัน (≥ 0.955) — อาจเพราะปรับเรียบต่างกันหรือไม่ได้ปรับเกณฑ์ตาม $q$ ซึ่งแยกไม่ได้ จึงเป็นเพียงข้อสังเกต
- **ข้อเสนอเชิงวิธี** การรายงาน MWC ควรระบุเกณฑ์นัยสำคัญที่ใช้ในแต่ละ $q$ ทุกครั้ง

### 4.4 ข้อมูลเชื่อถือได้แค่ไหน

**คำตอบ:** **การกรองและลดอัตราสุ่มถูกต้อง** และข้อสรุปในหัวข้อ 4.1–4.3 ไม่ขึ้นกับแหล่งข้อมูล แต่ **ความเด่นของ WNPMI ในแถบ 2–7 ปีขึ้นกับข้อมูล PSMSL หลัง ค.ศ. 2005** ซึ่งไม่ตรงกับ UHSLC จึงไม่สรุปว่า WNPMI เป็นดัชนีที่เด่นที่สุด

**หลักฐาน: การลดอัตราสุ่ม (Q7)**
- ตัวกรองลดทอนแถบหยุดได้จริง 70.07 dB และลดทอนองค์ประกอบน้ำขึ้นน้ำลงหลักได้ 77–99 dB (รูปที่ 13)
- รายวันต่างจากผลิตภัณฑ์รายวันของ UHSLC RMS 3.0 มม. · รายเดือนต่างจาก PSMSL ค่ามัธยฐานของผลต่างสัมบูรณ์ 1.1–1.2 มม. (ช่วงที่ datum คงที่)
- ถ้าลดอัตราสุ่มโดยไม่กรอง K1 และ P1 พับลงมาที่คาบ 365.2 วัน และ K2 ที่ 182.6 วัน — **ตรงกับคาบรายปีและครึ่งปีพอดี** การพับความถี่จึงไม่ได้แค่เพิ่มสัญญาณรบกวน แต่บิดเบือนฤดูกาลโดยตรง

![รูปที่ 13](../../figures/report/fig02_filter.png)

**รูปที่ 13** ผลตอบสนองเชิงความถี่ของตัวกรอง FIR Kaiser 261 แท็ป เทียบกับความถี่ขององค์ประกอบน้ำขึ้นน้ำลงหลัก

**หลักฐาน: ความแข็งแรงของข้อสรุป** (รูปที่ 14) สองฝั่งต่างกัน และดัชนีเดี่ยวเพียงพอ (ทั้งระนาบ) คงอยู่ 8/8 แบบ · WNPMI เด่นในแถบ 2–7 ปี 6/8 · ดัชนีประจำภูมิภาคช่วย 4/8

![รูปที่ 14](../../figures/report/fig13_robustness.png)

**รูปที่ 14** ข้อสรุปหลักเจ็ดข้อภายใต้การเตรียมข้อมูลแปดแบบ แต่ละช่องคำนวณใหม่ทั้งกระบวนการรวมถึงสมมติฐานว่างของแบบนั้น ตัวเลขขวา = จำนวนแบบที่ผ่าน

**หลักฐาน: สองคลังข้อมูลเกาะตะเภาน้อยไม่ตรงกันหลัง 2005** (รูปที่ 15)
- จนถึง 2005 ตรงกันระดับมิลลิเมตร (1990–2003 มัธยฐาน 0 มม., MAD 1.2 มม.) · 2006–2012 ผลต่างแกว่ง −70 ถึง +135 มม. · 2015–2019 คงที่ +100.7 มม.
- เอกสารผู้ผลิตข้อมูลอธิบายได้เกือบทั้งหมด:
  1. ตั้งแต่ 12 ต.ค. 2005 UHSLC ใช้มาตรวัดเรดาร์ของตนเอง ขณะที่ PSMSL น่าจะยังใช้มาตรวัดทุ่นลอยของกองทัพเรือ — คนละเครื่องมือ (UHSLC, 2020)
  2. UHSLC พบการเลื่อนระดับแบบขั้นบันไดใกล้ 1 เม.ย. 2012 และบวก 10 ซม. ให้ข้อมูลก่อนหน้า แต่ PSMSL ไม่ได้แก้แบบเดียวกัน — ตรงกับผลต่าง ~100 มม.
  3. แท่นมาตรวัดถูกพายุทำลาย ก.ค. 2013 (PSMSL ไม่มีข้อมูล 2013–2014) แท่นใหม่ใช้งาน มี.ค. 2016
  4. การทรุดตัวหลังแผ่นดินไหว 2004 (~10 ซม. ถึง 2021; Naeije et al., 2022) **ไม่ใช่** สาเหตุ เพราะสองคลังวัดจากแท่นเดียวกัน จึงหักล้างกันในผลต่าง

![รูปที่ 15](../../figures/report/fig14_ktn_datum.png)

**รูปที่ 15** ผลต่างรายเดือน PSMSL − UHSLC (ลดอัตราสุ่มตามขั้นที่ 2) ของเกาะตะเภาน้อย ปรับศูนย์ที่ช่วง 1990–2003 เส้นประ = เหตุการณ์ที่มีเอกสารยืนยัน

- **ผลต่อ PASC** (แถบ 2–7 ปี ช่วงเดียวกัน 1985–2019) เปลี่ยนคลังข้อมูลแล้ว SOI และ Niño3.4 แทบไม่เปลี่ยน แต่ WNPMI ลดลงครึ่งหนึ่ง

  | ดัชนี | PSMSL (V5) | UHSLC (V6) | เปลี่ยน |
  | --- | ---: | ---: | --- |
  | SOI | 49.7 | 50.3 | แทบไม่เปลี่ยน |
  | Niño3.4 | 39.1 | 43.1 | แทบไม่เปลี่ยน |
  | WNPMI | 70.5 | 34.9 | ลดลงประมาณครึ่ง |

- WTC กับ WNPMI ของ PSMSL สูงกว่า UHSLC **เฉพาะช่วงที่สองคลังไม่ตรงกัน** (0.70 vs 0.41 ในปี 2006–2012 และ 0.60 vs 0.24 ในปี 2013–2019) · ในช่วงที่ตรวจสอบได้ (ก่อน 2006) DMI และ WNPMI ได้ PASC แถบ 2–7 ปีใกล้เคียงกัน (23.9% และ 23.0%)
- สองคลังเห็นตรงกันอีกข้อ: ช่วง 1985–2019 ทุกดัชนีมี coherence สูงกว่าทั้งอนุกรมชัดเจน (เช่น SOI แถบ 2–7 ปี ~50% เทียบกับ 16%) — สอดคล้องกับหลักฐานว่า ENSO กับมรสุมสัมพันธ์แน่นขึ้นหลังปลายทศวรรษ 1970 และ IOD บวกเกิดถี่ขึ้น (Wang et al., 2008; Abram et al., 2008) แต่แยกออกจากผลของคุณภาพข้อมูลช่วงต้นไม่ได้ *(อนุมาน)*

**เพราะอะไรจึงไม่สรุปว่า WNPMI เด่นที่สุด** ความเด่นมาจากข้อมูลช่วงที่มีข้อโต้แย้ง และกล่องของ WNPMI ไม่ครอบคลุมทะเลอันดามันด้วยซ้ำ (รูปที่ 2) สิ่งที่ข้อมูลรองรับคือ ระดับน้ำอันดามันสัมพันธ์กับทั้งโหมด ENSO และโหมดมหาสมุทรอินเดีย/มรสุม โดยในช่วงที่ตรวจสอบได้ ดัชนีประจำภูมิภาคมีบทบาทใกล้เคียงกัน

## 5. นำไปใช้ประโยชน์อย่างไร

### 5.1 ด้านชายฝั่งและทรัพยากรทางทะเล

**ทำไมสำคัญ** ปีที่น้ำอันดามันลงต่ำผิดปกติ (1997, 2006, 2019) ปะการังน้ำตื้นโผล่พ้นน้ำนาน 3–4 ชั่วโมงแทนปกติ 2 ชั่วโมง ติดต่อกัน 2–3 เดือน จนตายจำนวนมาก (นิพนธ์ พงศ์สุวรรณ, 2564) และงานติดตามแนวปะการังภูเก็ต 34 ปีระบุว่า ENSO และ IOD เป็นตัวขับหลักของการปกคลุมของปะการังน้ำตื้นในทะเลอันดามัน (Dunne et al., 2021)

| ผลที่ได้ | นำไปใช้ | ผู้ได้ประโยชน์ |
| --- | --- | --- |
| น้ำอันดามันลดลงในปี El Niño และ IOD บวก ด้วยกลไกที่ระบุได้ (คำตอบ 1–2) | ใช้ผลคาดการณ์ ENSO/IOD ที่หน่วยงานภูมิอากาศออกเป็นประจำ เป็น **สัญญาณเตือนล่วงหน้า** ว่าน้ำอาจลงต่ำผิดปกติหลายเดือน แล้วเตรียมเฝ้าระวังแนวปะการังน้ำตื้น ปรับจุดดำน้ำ หรือจำกัดการเข้าแนวปะการังช่วงน้ำลง | กรมทรัพยากรทางทะเลและชายฝั่ง, อุทยานแห่งชาติทางทะเล, ผู้ประกอบการท่องเที่ยว |
| อ่าวไทยไม่สัมพันธ์กับดัชนีใด (คำตอบ 1) | การวางแผนรับมือระดับน้ำในอ่าวไทยควรอิง **ฤดูกาล น้ำเกิด และมรสุม** ไม่ใช่ดัชนี ENSO ซึ่งตรงกับแนวทางที่หน่วยงานใช้อยู่ · **ไม่ควรนำคำเตือนของฝั่งอันดามันมาใช้กับอ่าวไทย** แม้สองฝั่งจะห่างกันไม่ถึง 450 กม. | หน่วยงานจัดการชายฝั่งฝั่งอ่าวไทย |
| ดัชนีเดี่ยวเพียงพอ (คำตอบ 3) | ระบบเฝ้าระวังใช้ดัชนีเพียงตัวเดียว (เช่น Niño3.4 หรือ SOI) ก็พอ ไม่ต้องรวมหลายดัชนีให้ซับซ้อน | ผู้พัฒนาระบบเตือน |

**ข้อควรระวังเรื่องเวลาเตือนล่วงหน้า**
- จากมุมเฟส ระดับน้ำ **ตาม** Niño3.4/SOI เพียง ~3 เดือน ส่วน DMI และ WNPMI นั้น **ระดับน้ำนำ** ดัชนี ดังนั้นถ้ารอดูค่าดัชนีที่วัดได้จริง จะได้เวลาเตือนสั้นมาก หรือช้าเกินไปในกรณีของ DMI ที่น้ำลดก่อน DMI ถึงจุดสูงสุด ~5 เดือน
- เวลาเตือนที่ยาวพอใช้งานจึงต้องมาจาก **การพยากรณ์** ENSO/IOD ล่วงหน้า ไม่ใช่จากค่าดัชนีที่วัดแล้ว *(อนุมาน)*
- งานนี้แสดงว่ามีความสัมพันธ์ แต่ **ยังไม่ได้สร้างหรือทดสอบระบบเตือน** อัตราเตือนถูกและเตือนผิดจริงยังไม่ทราบ (ดูงานต่อข้อ 5)
- อ่าวไทย: การตรวจไม่พบ ไม่ได้แปลว่าไม่มีผลเลย สัญญาณ ENSO อาจมีอยู่แต่เล็กเพียงไม่กี่เซนติเมตร จึงไม่มีนัยต่อการวางแผน แต่ยังไม่ควรสรุปว่าเป็นศูนย์

## 6. ข้อจำกัดและงานต่อ

**ข้อจำกัด**
- **Coherence ไม่ใช่เหตุและผล** ผลสอดคล้องกับกลไกที่มีงานรองรับ แต่ไม่ได้พิสูจน์กลไก
- **ข้อมูลเกาะตะเภาน้อยหลัง 2005 ไม่มีแหล่งที่สามมาตัดสิน** ข้อสรุปเรื่องสองฝั่งต่างกัน ทิศของความสัมพันธ์ และดัชนีเดี่ยวเพียงพอ ไม่ขึ้นกับปัญหานี้ (ผ่านทั้ง V6 และ V7) แต่เรื่องลำดับดัชนีและดัชนีประจำภูมิภาคขึ้นกับปัญหานี้โดยตรง
- **แถบ 8–16 ปีสรุปไม่ได้** 72 ปีมีรอบคาบทศวรรษน้อยเกินไป การไม่พบ coherence กับ PDO/TPI จึงไม่ได้ตัดอิทธิพลคาบทศวรรษออก
- **ไม่ได้ทดสอบผลต่างระหว่างสองฝั่งโดยตรง** ข้อสรุปมาจากฝั่งหนึ่งผ่านและอีกฝั่งไม่ผ่านในทุกแบบ
- ใช้มาตรวัดฝั่งละหนึ่งแห่ง · ไม่ได้ใช้การทดสอบนัยสำคัญเชิงพื้นที่ (Maraun & Kurths, 2004) · ลม reanalysis ก่อน 1979 ที่ใช้คำนวณ WNPMI น่าเชื่อถือน้อยกว่า

**งานต่อ**
1. ใช้ข้อมูลดาวเทียมใกล้ 7.83°N, 98.42°E หรือสถานีลังกาวีเป็นแหล่งที่สาม เพื่อหาการเลื่อนระดับ ณ วันเปลี่ยนเครื่องมือ (Ray et al., 2023)
2. Partial wavelet coherence ของ DMI และ WNPMI โดยควบคุม Niño3.4 — ดูว่ามีสารสนเทศอิสระจาก ENSO หรือไม่
3. เทียบ PSMSL 1951–1984 กับ 1985–2019 ด้วยวิธีเดียวกัน เพื่อแยกผลระบอบภูมิอากาศออกจากผลแหล่งข้อมูล
4. วิเคราะห์อ่าวไทยแยกฤดู (ธ.ค.–ก.พ. และ มิ.ย.–ส.ค.) เพราะสัญญาณ ENSO ในทะเลจีนใต้ผูกกับฤดูกาล
5. **ต่อยอดเป็นระบบเตือนน้ำลงต่ำฝั่งอันดามัน** ใช้ผลพยากรณ์ ENSO/IOD ย้อนหลังทำนายระดับน้ำ แล้ววัดเวลาเตือนล่วงหน้าและอัตราเตือนถูกหรือผิดเทียบกับเหตุการณ์ 1997, 2006, 2019
6. ใช้สายการคำนวณเดิมกับมาตรวัดอื่นฝั่งอันดามัน เพื่อยืนยันว่าผลไม่ได้เป็นลักษณะเฉพาะของสถานีเดียว

## ภาคผนวก ข การทำซ้ำและการตรวจสอบ

รูปทุกรูปสร้างจากไฟล์ผลใน `data/processed/` เท่านั้น

```bash
uv run python scripts/fetch_data.py && uv run python scripts/build_series.py
uv run python scripts/verify_decimation.py                                   # คำถาม 4 (Q7)
uv run python scripts/run_wtc.py                                             # คำถาม 1–2 (Q1, Q2, Q8)
uv run python scripts/run_mwc_null.py && uv run python scripts/run_mwc.py    # คำถาม 3 (Q3–Q5)
uv run python scripts/null_control.py --nrep 1000                            # คำถาม 3 (Q6)
uv run python scripts/sensitivity.py --all                                   # ทดสอบความไว 8 แบบ × 2 สถานี
uv run python scripts/make_figures.py
uv run --group report python scripts/make_infographics.py
```

การตรวจสอบความถูกต้องของการคำนวณ
1. MWC ที่ $q = 1$ เท่ากับ WTC (ผลต่างสูงสุด $7.8 \times 10^{-16}$)
2. ถ้า $Y = X_1 + X_2$ แล้ว MWC ของ $Y$ กับ $\{X_1, X_2\}$ = 1 ทุกจุดใน COI
3. สัมประสิทธิ์ FIR ตรงกับ `scipy.signal.firwin` (ผลต่าง $< 10^{-18}$)
4. WTC ตรงกับ `pycwt.wct`
5. แบบ V0 ให้ผลตรงกับการคำนวณหลักทุกหลัก
6. ชุดทดสอบอัตโนมัติ 77 รายการผ่านทั้งหมด
